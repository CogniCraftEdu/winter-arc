# Winter Arc · 21 Days Hard Challenge

21-day discipline tracker: 22 Oct → 11 Nov 2026 (change `START`/`END` in `src/config.js`). React + Vite, no backend; data lives in the browser (localStorage).

```
npm install
npm run dev      # local
npm run build    # static site in dist/ — host anywhere (Netlify, Vercel, GitHub Pages)
```

- **Today** – quote of the day, the one thing, stopwatch (work hours), 6 non-negotiables, hour-by-hour Expected vs Actual schedule, notes & reflection, bonus habits, water, evening check-in
- **Reel** – a 9:16 daily Day Card built from today's real data: empty (morning hook), animated fill, filled (evening reveal), PNG download, recording view
- **Plan** – fill the flexible hours (9–1, 2–9) the night before
- **Journey** – day grid + GitHub-style consistency frame, **odds model** (chance of finishing, streak survival, editable assumptions), streaks, weekly reviews, arc goals, targets, JSON export/import

Rules: only today is editable (the past is locked), a day is "won" only when all 6 rules pass. Dates and rules are in `src/config.js`.
